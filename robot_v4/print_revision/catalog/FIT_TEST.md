# ทดลองระยะสวมก่อนผลิตชุดใหญ่

ใช้ `output_R2/TRIAL_ONLY` กับเครื่อง เส้น profile และท่าพิมพ์เดียวกับชุดใหญ่ ชื่อไฟล์ระบุค่าทดลอง ไม่ใช่ค่าที่รับรองแล้ว

1. **เพลา D:** ลอง clearance เส้นผ่านศูนย์กลาง 0.0/0.1/0.2/0.3 มม. ค่าด้านแบนเริ่มครึ่งหนึ่งของ clearance เลือกชิ้นที่สวมได้ด้วยมือ ไม่ต้องตอก บันทึกเพลาทั้งสี่ตัว ไม่ถือว่าเพลาชิ้นแรกแทนได้ทุกตัว
2. **แกนบานพับ:** ลอง clearance 0.0/0.1/0.2/0.3 มม. มีทั้งรูพิมพ์แนวตั้งและแนวนอน ใช้รูแนวนอนแทนบล็อก รูแนวตั้งแทน carrier เลือกค่าที่ผ่านทั้งคู่แล้วทดสอบบล็อกจริงหนึ่งข้างพร้อม carrier สองชิ้น
3. **Insert:** รู R2 Ø4.4/4.5/4.6/4.7/4.8 มม. สำหรับinsertOD5ยาว4mm (ค่าเริ่มทดลอง ยังไม่สอบเทียบ) ทีละ 0.1 มม. ทดลอง PETG/TPU ตามวัสดุและทิศรูจริง ฝัง insert ด้วยวิธีที่ร้านใช้จริง ต้องไม่แตก ไม่หมุนตามสกรู ไม่หลุดเมื่อขันฝาหรือ wedgelet
4. **ยาง:** วงแหวนทดลอง ID43.4/43.6/43.8/44.0 มม. หนา 4 มม. เลือกค่าที่สวมดุม Ø44 ได้และไม่หมุนฟรี จากนั้นพิมพ์ยางเต็ม 16 มม. หนึ่งชิ้นยืนยันซ้ำก่อนครบสี่ล้อ
5. **น็อตดุมและสกรูล็อก:** ใส่ M3 จริงผ่านช่องข้างดุม หันหน้าราบของน็อตตามช่อง ใส่สกรูตัวหนอนทางรูที่ขอบดุม ขันให้แตะด้านแบนของเพลา ดุมต้องไม่หมุนหรือเลื่อนโดยการทดสอบแรงมือ ติดตามรอยแตก/การยุบ หากน็อตหมุนให้ปรับช่องตามของจริงและพิมพ์ซ้ำ
6. **ฝา:** ใช้ชิ้น TPU wall/lid ทดสอบ insert และน็อตฝา ขัน/คลายซ้ำอย่างน้อย 5 รอบ ต้องไม่หมุนฟรีหรือดึง insert หลุด
7. **Wedgelet:** ใส่แกน เหล็ก และสกรูจริง ปลายต้องลงพื้นด้วยน้ำหนักตัวเอง ยกได้จนตัวหยุดโดยไม่ติดและไม่ดึง insert หลุด ผลแรงมือเป็นเกณฑ์ประกอบเท่านั้น ไม่ใช่การรับรองแรงชน
