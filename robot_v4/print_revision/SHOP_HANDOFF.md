# ใบส่งงานร้านพิมพ์ — Robot V4 Print R1

**ขอราคาและพิมพ์ชิ้นทดลองก่อน ไม่ใช่ใบอนุมัติผลิตชุดใหญ่** ห้ามเปลี่ยนวัสดุ สเกล รูประกอบ หรือซ่อม mesh โดยไม่ส่งรายละเอียดกลับให้แก้ต้นฉบับ

## ข้อมูลที่ร้านต้องระบุ

| รายการ | คำตอบร้าน |
|---|---|
| ชื่อร้าน / ผู้รับงาน | รอยืนยัน |
| เครื่อง / พื้นที่พิมพ์ใช้ได้จริง XYZ | รอยืนยัน |
| หัวฉีด / ความกว้างเส้น / layer height | รอยืนยัน |
| Slicer / version / profile | รอยืนยัน |
| TPU 95A ยี่ห้อ/รุ่น และ PETG ยี่ห้อ/รุ่น | รอยืนยัน |
| Brim / support / วิธีเก็บงาน | รอยืนยัน |
| ราคาทดลอง รวมเก็บงาน/ส่ง | รอยืนยัน |
| ราคาชุดเต็ม รวมเก็บงาน/ส่ง | รอยืนยัน |
| น้ำหนักและเวลาพิมพ์แยกตาม STL | รอยืนยัน |

ถาดปัจจุบันประมาณ **190.5 × 217.3 × 54 มม.** ก่อน brim ฐานใช้ได้จริง 220 × 220 มม. ไม่พอสำหรับ brim 5 มม. โดยวางตรงตามแกน ให้เลือกเครื่องที่รองรับชิ้นเดียวรวม brim ที่ตกลง ห้ามตัดแบ่งตัวถังเพื่อแก้เรื่องฐานพิมพ์

## การตั้งค่าตั้งต้นสำหรับลองสไลซ์

ใช้หัวฉีด 0.4 มม. และ layer 0.2 มม. เป็นค่าประเมินเริ่มต้น ร้านต้องยืนยัน profile ตามวัสดุจริง

| กลุ่ม | วัสดุ | ตั้งต้น | ท่าที่ส่งออก / สิ่งต้องตรวจ |
|---|---|---|---|
| ถาดและฝา | TPU 95A | 4 walls, 60% gyroid | พื้นลงฐาน; ฝามีหลังคาโค้งและช่องสายพาน ต้องตรวจ support ถอดได้ |
| ยางล้อ | TPU 95A | 4 walls, เริ่มประเมิน 60% gyroid | หน้าวงแหวนลงฐาน ตรวจความยืดหยุ่นและ fit กับดุม |
| บานพับ/ดุม | PETG | 4 walls, ≥80% infill | รูแกนบล็อกเป็นแนวนอน; carrier/ดุมวางแกนหลักแนวตั้ง |
| ถาดแบต/แท่น/เสา/ฐานมอเตอร์ | PETG | 4 walls, เริ่ม 80% infill | ตรวจ slot สายรัด รูสกรู และช่องน็อต ไม่มีการลดเนื้อรอบรูบานพับต่ำกว่า 1.6 มม. |
| เสา Hall / collar | PETG | 4 walls, เริ่ม 80% infill | เสา Hall วางนอนใน STL ตรวจ support ที่ยื่นออก |

ชุดขนาด รู และจำนวนใช้ `output/manifest.json` ของ build ล่าสุด อย่าใช้คู่มือ V4 เดิมแทนรายการนี้ ไม่มีชิ้น mirror ให้ร้านสร้างเองแล้ว

## ผลที่ต้องส่งกลับ

- ไฟล์โครงการ slicer จริง เก็บ printer/material profile ท่าวางชิ้น support และจำนวนให้ครบ
- ภาพ layer preview ของบานพับ รู insert ช่องน็อตดุม ฝาหลังคาโค้ง และแนวสายพาน
- ตารางน้ำหนักและเวลาต่อ **หนึ่งชิ้นของแต่ละ STL** โปรแกรมคูณจำนวนเอง รวมข้อมูล support แยกออกจากมวลชิ้นที่จะอยู่บนรถ
- ใบเสนอราคาแยกชิ้นทดลอง/ชุดเต็ม วัสดุ งานเก็บผิว และส่ง ไม่ถือว่างบพิมพ์เส้นเดิม 550 บาทเป็นราคาจ้างร้าน
- ผลการทดลองตาม `FIT_TEST.md` และ SHA256 build ที่ใช้อยู่ หากเปลี่ยน profile/วัสดุ/ท่าพิมพ์ในจุดสวม ต้องลองจุดนั้นใหม่

เงื่อนไขงบ: รวมอะไหล่ โลหะ ชิ้นพิมพ์ทดลอง ชุดเต็ม และค่าส่งทั้งโครงการไม่เกิน **6,000 บาท** หากเกิน ให้รายงานก่อนผลิต ไม่มีคำสั่งซื้อหรือการอนุมัติสั่งผลิตในใบนี้
