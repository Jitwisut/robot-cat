## แบบตอบกลับสั้น

| รายการที่ต้องเก็บ | คำตอบ / แนบหลักฐาน |
|---|---|
| ร้าน / SKU / variant / จำนวนพร้อมส่ง / วันตรวจ | รอยืนยัน |
| ราคาแยกหน่วยขาย + VAT + ส่ง / ระยะเวลาราคามีผล | รอยืนยัน |
| Drawing/รูปคาลิปเปอร์/ฉลากสินค้าที่จะส่ง | รอยืนยัน |
| มวลรวมสาย/ปลั๊ก / ขนาดตัว / พื้นที่สายและเครื่องมือ | รอยืนยัน |
| ข้อมูลไฟ/กระแส/รุ่นต่อเข้ากัน | รอยืนยัน |
| งานพิมพ์:เครื่อง/วัสดุ/profile/brim/support/slicerproject | รอยืนยัน |
