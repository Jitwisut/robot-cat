# ขอราคา TKK3D — R3

เตรียมให้ผู้ใช้ส่งเอง; ยังไม่ส่งหรือสั่งผลิต

ติดต่อ: LINE @tkk3d; sale@tkk3dprinting.com;092-599-5661

ขอใบเสนอราคา Robot V4 Print R3 ยังไม่สั่งพิมพ์ตัวถังครับ ใช้ TPU95A/PETG ตัวถังชิ้นเดียว 4WD ตาม manifest ใน DRAFT_REVIEW.zip ขอแยกราคางานดังนี้:
1. รับอะไหล่ที่ผู้ใช้ส่งให้ วัดมอเตอร์ขับแยก4ตัว รูยึด บ่า เพลาD projection/flat/thread depth; มอเตอร์อาวุธ แบต ESC PCB หลังต่อขา ขั้วต่อ/สายและเครื่องมือขัน ชั่งทุกชิ้น แนบภาพฉลากและคาลิปเปอร์ ตาม MEASUREMENTS.md/measurement_log.json
2. ล็อกเครื่อง/พื้นที่ใช้งานXYZ/nozzle/TPU95Aยี่ห้อ/PETG/slicer version/profileไฟล์/brim/support/orientationก่อนทดลอง ไม่ mirror เองหรือ scale STL
3. รอบ1เลือกcoupon Dshaft pin insert tyreIDทีละ0.1mmจากTRIAL_ONLY; ห้ามพิมพ์ตัวถัง จากค่าที่เลือกผมสร้างCADใหม่ แล้วรอบ2พิมพ์ดุม+ยางเต็ม1ชุด บานพับ+carrierหนึ่งข้าง ฝาจำลองตามFIT_TEST.md วัด/ลองเพลาครบ4 ดุมไม่หมุน/เลื่อน ยางไม่ฟรี hingeไม่ติด wedgeletแน่น ฝาขันคลาย5รอบ insertไม่หมุน/หลุด ขอภาพ/วิดีโอและกรอกfit_log.json
4. ราคาเต็มตามmanifest รวม supportที่ถอดได้ ฝังinsert14จุด เก็บผิวโดยไม่ขยายรูเอง น้ำหนักชิ้นอยู่บนรถแยกจากsupport เส้น/profile/ท่าพิมพ์ต้องเหมือน trial ส่งไฟล์โครงการslicerและผล thin-wall/brim/access/support ทุกชิ้น
5. ราคาแยกวัด/ทดลองสองรอบ/แก้ซ้ำ/พิมพ์เต็ม/finish/ภาษี/ส่ง/ระยะเวลายืนราคา ตัวถังต้องวางได้ครบรวมbrim ใช้bed>=ขนาดชิ้นในmanifest ห้ามตัดแบ่งถาด
