# V4 Print R1 — ชุดต้นแบบเพื่อปิดงานพิมพ์และประกอบ

**สถานะ: DRAFT — ยังไม่อนุมัติพิมพ์ชุดใหญ่** ผลล่าสุดและรายการที่ยังค้างอยู่ใน [output/STATUS.md](output/STATUS.md) ส่วนรายงานเครื่องอ่านได้อยู่ใน `output/build_report.json` แบบ V4 เดิมและผลจำลองเดิมยังอยู่ที่เดิม ไม่ได้ถูกแทนที่

สร้าง STEP/STL ได้โดยไม่ต้องเปิด Fusion ด้วย CadQuery ซึ่งรองรับการส่งออกทั้งสองรูปแบบ ([เอกสาร](https://cadquery.readthedocs.io/en/latest/importexport.html)) STEP เปิดใน Fusion ได้ แต่ไม่มี Fusion feature timeline; สคริปต์และ `inputs.json` เป็นแบบพาราเมตริกหลักของ revision นี้

## งานที่ทำแล้ว

- เพิ่มรูยึดมอเตอร์ขับแบบวัดแยกทั้ง 4 ตัว ช่องยึดตัวตัดไฟ ถาดแบตพร้อมสายรัด 2 เส้น แท่นอุปกรณ์ PETG และเสารอง 4 ตัวแยกพิมพ์
- เพิ่มฐาน PETG 2 ชิ้นยึดแผ่นมอเตอร์อาวุธเข้าพื้น TPU พร้อมช่องน็อต ย้ายเพลาหน้าจาก y=10 เป็น **y=18 มม.** ยกแกนมอเตอร์อาวุธจาก z=32 เป็น **42.5 มม.**
- ทำฝาครอบโค้งเหนือมอเตอร์ สูงสุด z=63 มม. ล้อยังคงสูงสุด z=64 มม. มีช่องสายพานในฝา bulkhead และ brace บน; **brace บน/ล่างใช้คนละ DXF แล้ว**
- แก้รอกมอเตอร์เป็น D30 ร่องราก D27 เหมือนดุม เพื่อให้รอบขับ **1:1** จริง เพิ่ม boss และรูต๊าปสกรูตัวหนอน พร้อมรูแม่เหล็กสมดุลสองรู
- เปลี่ยน knuckle เป็นทรงกระบอกเชื่อม spine พร้อมเนื้อรอบรูอย่างน้อย **1.6 มม.** เพิ่มน็อตโลหะและสกรูล็อกดุมล้อ รูสวมทั้งหมดปรับจากผลทดลองได้
- ส่งออกชิ้นพิมพ์เป็น Z ขึ้น วางฐาน Z=0 พร้อม carrier ซ้าย/ขวาแยกไฟล์ มี STEP assembly, DXF ชิ้นแผ่น และ STEP ชิ้นกลึง
- ตรวจ exact CAD self-interference ด้วย OpenCascade, ชิ้นชนกัน, วงหมุนใบเผื่อ 1 มม., wedgelet ทุก 1° ระหว่าง −2°…+14° และตรวจ STL โดยไม่ซ่อม mesh อัตโนมัติ
- คำนวณมวล จุดศูนย์ถ่วง และ tensor ความเฉื่อยจากชิ้น CAD/รายการน้ำหนัก แล้วใช้ใน MuJoCo โดยไม่แทนค่าจุดศูนย์ถ่วงเดิมด้วยค่าที่ปรับให้ผ่าน

ข้อมูลอะไหล่ที่ยังไม่วัดใช้ **nominal เพื่อสร้างต้นแบบเท่านั้น** ไม่ใช่ขนาดที่ร้านควรผลิตครบชุด รุ่นนี้ยังต้องยืนยันเรื่องน้ำหนัก ราคา ระยะสวม การเข้าถึงน็อตและการเดินสายจากของจริง

## วิธีปิดงานต่อ

1. กรอก [MEASUREMENTS.md](MEASUREMENTS.md) และใส่ค่าใน `inputs.json` → `hardware` → `actual` แนบหลักฐานขนาด/น้ำหนัก และระบุ `verified: true` เฉพาะรายการที่ยืนยันแล้ว
2. ให้ร้านกรอก [SHOP_HANDOFF.md](SHOP_HANDOFF.md) และขอราคา ทั้งชิ้นทดลองและชุดเต็ม ห้ามสั่งชุดเต็มหากยอดโครงการเกิน 6,000 บาท
3. สร้างชุดต้นแบบใหม่ ให้ร้านพิมพ์ชิ้นใน `output/TRIAL_ONLY` ตาม [FIT_TEST.md](FIT_TEST.md) ด้วยเครื่องและวัสดุเดียวกับงานจริง แล้วใส่ค่าที่เลือกลง `fit`
4. สร้างใหม่หลังปรับ fit ระบุผลตรวจชิ้นทดลอง พร้อม `sha256_build` ของแบบนั้น หากปรับค่าต้องสร้างและตรวจใหม่จนหลักฐานตรงกับแบบสุดท้าย
5. ร้านตรวจ slicer ทุกชิ้น ส่งไฟล์โครงการจริงและรายงานน้ำหนัก/เวลา/support กรอก `shop` กับ `slicer` และหลักฐานราคาใน `cost`
6. ตรวจทางประกอบแบบตาม [ASSEMBLY.md](ASSEMBLY.md) ด้วยอะไหล่จริง/ชิ้นทดลอง และลงผลใน `assembly` ขั้นนี้รวมการเข้าถึงสกรูและขั้วต่อ โดยไม่ต้องเปิดอาวุธ
7. สร้าง CAD → จำลอง → สร้างรายงานรวมซ้ำ แล้วใช้ `--release` เมื่อรายการค้างหมด โปรแกรมจะปฏิเสธ release หากข้อใดไม่ผ่าน

หลักฐานใช้ไฟล์จริงในโฟลเดอร์ `evidence/` เช่น รูปพร้อมไม้บรรทัด ตารางชั่ง รายงานทดลอง หรือใบเสนอราคา เก็บชื่อไฟล์ไว้ในช่อง `evidence`/`project_file`/`report_file` ให้เส้นทางสัมพันธ์กับโฟลเดอร์นี้ ข้อมูลที่ยังไม่มีให้คง `null` ไม่ใช้เลขศูนย์แทนช่องว่าง

## คำสั่งจากโฟลเดอร์โปรเจกต์

```sh
python3 -m venv .venv-v4-print
.venv-v4-print/bin/python -m pip install -r robot_v4/print_revision/requirements.txt
.venv-v4-print/bin/python robot_v4/print_revision/build.py
.venv/bin/python robot_v4/print_revision/simulate.py
.venv-v4-print/bin/python robot_v4/print_revision/build.py
.venv-v4-print/bin/python -m unittest discover -s robot_v4/print_revision/tests -v
```

MuJoCo ใช้ `.venv` เดิม หากเครื่องอื่นไม่มี ให้ติดตั้ง MuJoCo/NumPy ใน venv ของเครื่องนั้น ใช้ผลจำลองจาก build เดียวกันเท่านั้น คำสั่ง `build.py --release` จะสร้าง `output/RELEASED` เมื่อผ่านครบ ห้ามแจกโฟลเดอร์ `DRAFT` โดยเปลี่ยนชื่อเป็นชุดพร้อมผลิต

## ข้อจำกัดที่ยังเปิดอยู่

- ไม่มีเครื่องพิมพ์หรือ slicer ของร้านให้ตรวจใน session นี้ จึงยังไม่มีไฟล์โครงการ slicer หรือ G-code ที่ยืนยันแล้ว
- ยังไม่มีขนาด น้ำหนัก และผลทดลองของอะไหล่จริงครบ จึงยังไม่มีผล physical fit หรือราคารวมที่ยืนยัน
- มวลจาก CAD ยังใช้สัดส่วนเนื้อพิมพ์ประมาณ 85% สำหรับถาด/ฝา และ 80% สำหรับ PETG/ยางล้อ ต้องแทนด้วยน้ำหนัก slicer และชั่งจริง **ค่าเป้าหมาย 1,900 กรัมยังไม่ผ่าน** แม้ประมาณการอยู่ต่ำกว่า 2,000 กรัม
- โหลดล้อหลังจากสมดุลเชิงสถิตกับแรงสัมผัส MuJoCo ต่างกันได้เพราะ wedgelet สัมผัสพื้นและการเอียงตัวรถ ให้รายงานทั้งสองค่า ห้ามใช้ผลจำลองแทนการชั่งโหลดเพลาจริง
- MuJoCo เป็นโมเดล rigid body ใช้รูปชนลดรูป ไม่ใช่ FEA และยังไม่ได้ทดสอบความแข็งแรงหลังชน ผลทดสอบเฟิร์มแวร์และพร้อมแข่งอยู่นอกขอบเขต revision นี้
