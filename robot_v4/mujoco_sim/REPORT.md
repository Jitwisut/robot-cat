# จำลอง 3D ด้วย MuJoCo: V2 vs R3 vs V4 (3–4 ต.ค. 2026)

**สิ่งที่เป็น:** จำลองฟิสิกส์ของแข็ง (rigid body) แบบ 3D ใน MuJoCo 3.14
- มีล้อ มอเตอร์ไฟฟ้ากระแสตรงที่คิดแรงต้านไฟย้อนกลับ (back-EMF) เซอร์โวที่จำกัดความเร็วตามของจริง ใบหมุน และบานพับครบทุกคัน
- ใช้หน้าสัมผัสแบบนุ่มของ MuJoCo (soft contact)
- ใบ V4 หมุนด้วยความเร็วและแรงเฉื่อยจริง ขับด้วยแบบจำลองมอเตอร์ D3536 และ ramp ของเฟิร์มแวร์

**สิ่งที่ไม่ใช่:**
- ไม่ใช่ FEA ชิ้นงานไม่บิดไม่แตก
- ไม่มีคนขับจริง ใช้ "คนขับอัตโนมัติ" กติกาเดียวกันทุกคัน
- **ความแรงที่ใบส่งให้คู่ต่อสู้ขึ้นกับค่าความแข็งของหน้าสัมผัส (`solref`) ที่ตั้งเอง** จึงรันหลายค่า และยังต้องยืนยันด้วยการทดสอบจริง

**รันซ้ำได้** (ต้องสร้าง venv ก่อน: `python3 -m venv .venv && .venv/bin/pip install mujoco numpy "imageio[ffmpeg]"`):

## สิ่งที่การจำลองเจอใน V4

| ปัญหา | สาเหตุ | ผล |
|---|---|---|
| **skirt แบกน้ำหนักรถแทนล้อ** (≈16 จาก 18.6 N) จนดันได้แค่ 2–4 N | แผ่นที่ห้อยตรงทำตัวเป็นเสาค้ำ แรงเสียดทานกับพื้นกันไม่ให้ขอบล่างไถลออก | **แก้แล้ว** (ดูหัวข้อ skirt) |
| **ลิ่มของ R3 มุดใต้ข้างและท้ายได้** (69–100%) | skirt บานพับ: ปลายลิ่มสอดเข้าใต้ขอบแล้วงัดแผ่นขึ้นได้ | **แก้แล้ว:** เปลี่ยนเป็น skirt ยึดตายเอียง 35° สูงจากพื้น 0.5 มม. ตอนนี้มุดได้ 0% |
| **ตอนเร่งใบ หัวรถทิ่มจนฟันตีพื้น** | V4 หน้าหนัก จุดศูนย์ถ่วงอยู่หลังเพลาหน้าแค่ประมาณ 1 มม. แรงบิดสะท้อน (≈0.2 N·m) จึงมากกว่าแรงกันทิ่มจากน้ำหนัก (≈0.02 N·m) | **แก้แล้ว:** เพิ่ม nose skid UHMW สูงจากพื้น 1 มม. หัวทิ่มได้ไม่เกินประมาณ 0.9° แล้วฟันยังห่างพื้น |
| **V4 หน้าหนัก** ล้อหลังรับน้ำหนักแค่ประมาณ 5% ดันได้ 8.5 N จากที่ควรได้ 11 N | ใบ มอเตอร์อาวุธ และแผ่นตั้ง อยู่หน้าทั้งหมด | ยังไม่ได้แก้ |
| **ใบของ V4 งัดลิ่มลาดของ R3 ไม่ได้** | ดูหัวข้อ "ใบเจอลิ่มต่ำ" | ลองแก้ 4 ทาง ไม่มีทางไหนได้ผล จึงยังไม่เปลี่ยนแบบ |

**บั๊กในโมเดลจำลองเองที่เจอและแก้แล้ว:**
- ฟันที่จำลองเป็นกล่องเดียวมีมุมกวาดรัศมีถึง 31.8 มม. แล้วขูดพื้น (ฟันจริงยาว 29.5 มม.) แก้เป็นกล่องแคบ 2 ชิ้นต่อฟัน
- เซอร์โวของ lifter ไม่ได้จำกัดความเร็ว จึงสะบัดเหมือนตัวพลิก (flipper) จน R3 พลิก V4 คว่ำได้ แก้เป็น 60° ต่อ 0.16 วินาทีตามเซอร์โวจริง แล้วรันใหม่ทั้งหมด

## Skirt: เลือกแบบจากการจำลอง

**วิธีทดสอบ (`flank_test.py`):**
- V4 จอดนิ่ง ให้ V2 หรือ R3 พุ่งชนข้างหรือท้ายที่คันเร่งเต็ม lifter ทำงานตามปกติ
- นับว่า "มุดใต้ได้" เมื่อล้อ V4 รับน้ำหนักน้อยกว่า 25% นานเกิน 0.25 วินาที หรือ V4 เอียงเกิน 5°

**ผลแต่ละแบบ** (`skirt_variants.py`; ตัวเลขคือ R3 ชนข้าง / R3 ชนท้าย / V2 ชนข้าง / V2 ชนท้าย, และแรงดันของ V4):

| แบบ skirt | มุดใต้ได้ | V4 ดันได้ | ล้อรับน้ำหนักตอนพัก |
|---|---|---:|---:|
| ไม่มี skirt | 100% / 100% / 0% / 29% | – | – |
| บานพับเอียง 35° | 66% / 100% / 0% / 0% | 7.8 N | 98% |
| บานพับ จำกัดยก 5° | 66% / 100% / 0% / 0% | 8.0 N | 98% |
| บานพับ + สปริง | 0% / 0% / 0% / 0% | **6.6 N, เลี้ยวช้าลง 27%** | **80%** |
| **ยึดตาย สูง 0.5 มม. (เลือกแบบนี้)** | **0% / 0% / 0% / 0%** | **8.5 N** | 99% |
| ยึดตาย สูง 1.0 มม. | 0% / 0% / 0% / 0% | 8.0 N | 99% |

**ความคลาดเคลื่อนตอนประกอบจริง** (`skirt_tolerance.py`; สุ่มความสูงขอบ):
- สูง 0–1.5 มม.: มุดใต้ได้ 0% ทุกกรณี
- สูง 1.5–2.5 มม.: R3 มุดได้ 29% เฉพาะตอนชนท้าย

แนบท้ายคู่มือผลิต: ทำรูยึดเป็นร่องเพื่อปรับความสูงให้ได้ 0.5 มม. บนพื้นสนามจริง

## ใบเจอลิ่มต่ำ: ลองแก้ 4 ทาง (ไม่ได้ผล)

ทุกทางทดสอบแบบเดียวกัน: V4 ใบหมุนเต็มรอบ พุ่งชนหน้าตรงๆ ทางละ 16–24 ครั้ง แล้วนับว่าคู่ต่อสู้ลอยเกิน 10 ซม. กี่ %

| ทางแก้ | R3 ลอย | V2 ลอย (V2 วิ่งเข้ามาด้วย) | หมายเหตุ |
|---|---:|---:|---|
| แบบปัจจุบัน | 0–6% | 62% | |
| wedgelet บานพับตรงกลางระหว่างจาน | 0% | ไม่ชัดเจน | ไม่ช่วย และหนักขึ้น 25 กรัม |
| มอเตอร์ล้อเร็วขึ้น (620 rpm) | 6% | 62% | ไม่ช่วย |
| ทดรอบใบลง 1.5:1 (bite มากขึ้น) | 0% | **88%** | ช่วยเฉพาะตอนเจอ V2 แต่พลังงานใบลดเหลือประมาณครึ่ง |
| ลดระยะฟันกับพื้นเหลือ 1.5 มม. + ลด nose skid เหลือ 0.5 มม. | 0–6% | 44% | ไม่ช่วย |

**ถ้าคู่ต่อสู้จอดนิ่ง ใบแทบไม่ทำให้ใครลอยเลย ทุกแบบ** (`attack_angle_test.py` ทั้งด้านหน้า ข้าง และท้าย)

**ข้อสรุป:**
- ใบหมุนแนวตั้งต้องมีขอบที่ฟันงัดเข้าไปข้างใต้ได้
- ลิ่มลาด 25° ของ R3 และใบตักของ V2 ตอนจอดนิ่ง (หัวคว่ำ สูง 2.1 มม.) ทำให้ฟันได้แค่ปัดผิว
- V2 ลอยได้ก็ต่อเมื่อวิ่งเข้ามา เพราะตอนเร่ง V2 เงยหน้า ใบตักยกขึ้นไปที่ 9.5 มม.

**จึงไม่เปลี่ยนแบบในรอบนี้** ถ้าต้องการให้ใบได้ผลกับลิ่ม ต้องเปลี่ยนแนวคิดอาวุธ (เช่นใช้ใบหมุนแนวตั้งที่ใหญ่และช้าลง มีฟันน้อยลง) ซึ่งเป็นงานใหญ่

## ผลการปะทะ (`duels.json`; V4 แบบสุดท้าย)

**วิธีรัน:**
- สุ่มจุดเริ่มห่างกัน 0.5–1.0 ม. หันหน้าแบบสุ่มมีความคลาด
- ทั้งสองคันใช้คนขับอัตโนมัติแบบเดียวกัน คือหันเข้าหาแล้วพุ่งชน ปะทะครั้งละ 6 วินาที
- V4 เร่งใบจากหยุดนิ่ง
- เปลี่ยนค่า 3 ตัว อย่างละ 2 ค่า: μ 0.4 / 0.8, solref 0.004 / 0.002, สนาม 2.4 / 1.5 ม. รวม 8 ชุด ชุดละ 24 ครั้ง ต่อคู่

|---|---|---|---|---|
| **V4 vs V2** | **12% / 35% / 58%** (ทำให้หมด 0–29%) | **0% ทุกชุด** | 42–88% | V2 ลอยเกิน 10 ซม. ใน 17% ของการปะทะ จบแบบคว่ำ 6% |
| **V4 vs R3** | **8% / 27% / 83%** | 0–4% | 17–92% | R3 ไม่ลอยเลย ในครั้งที่ V4 ได้เปรียบ ล้อ R3 รับน้ำหนักน้อย (น่าจะเป็นตอน V4 ขึ้นไปอยู่บนลิ่มของ R3) และถูกดันติดผนัง |

**ส่วนที่ต่างกัน:**
1. **แบบลดรูปประเมิน skirt บานพับดีเกินจริง** เพราะมองไม่เห็นว่าแผ่นจะยกตามลิ่ม
2. **แบบลดรูปประเมินใบดีเกินจริงเมื่อเจอขอบต่ำ** เพราะไม่ได้คิดเรื่อง bite
3. **ใน 3D ทุกคันชนหน้ากันเป็นส่วนใหญ่** เพราะคนขับอัตโนมัติไม่ได้พยายามอ้อมไปด้านข้าง **ข้อนี้เข้าข้าง V4 และ R3**
4. แบบลดรูปนับทั้งแมตช์ ส่วน 3D นับการปะทะ 6 วินาทีครั้งเดียว ตัวเลขจึงเทียบกันได้แค่ทิศทาง

## สิ่งที่ควรทำต่อ

1. **ทดสอบจริงที่ตัดสินผลทั้งหมด:**
   - ให้ใบตีลิ่มเหล็กที่ต่ำ 1 มม. ทั้งตอนลิ่มจอดนิ่งและตอนวิ่งเข้ามา แล้ววัดว่ากระเด็นสูงแค่ไหน
   - ตั้ง skirt ให้สูง 0.5 มม. บนพื้นจริง
   - ชั่งหาจุดศูนย์ถ่วงจริงของรถ
2. **V4 หน้าหนัก:** ถ้าจุดศูนย์ถ่วงจริงใกล้เพลาหน้าแบบนี้ ต้องพิจารณาจัดวางชิ้นส่วนใหม่
3. **อาวุธเจอลิ่ม:** ถ้าในการแข่งมีหุ่นลิ่มเยอะ ให้พิจารณาทดรอบใบ 1.5:1 (งัดได้ดีขึ้น แต่พลังงานลดลง) หรือออกแบบอาวุธใหม่
