# Robot V4 — ตรวจความพร้อมพิมพ์ 3D วันที่ 7 ต.ค. 2026

**ผล: ยังไม่พร้อมพิมพ์ครบชุดเพื่อประกอบใช้งานจริง พิมพ์ชิ้นทดลองบางส่วนได้**

ตรวจไฟล์ STL ปัจจุบันทั้ง 9 ไฟล์และโค้ดสร้าง CAD โดยไม่ได้แก้แบบ ไม่ได้เปิด slicer หรือทดสอบชิ้นพิมพ์จริง

## ผลตรวจ STL โดยตรง

ทุกไฟล์เป็น binary STL ที่อ่านได้ครบ มีผิวเชื่อมต่อ 1 ชุด ขอบเปิด 0 ขอบ non-manifold 0 ทิศทางขอบของผิวสอดคล้องกัน ไม่มีสามเหลี่ยมพื้นที่ศูนย์หรือหน้าซ้ำ และปริมาตรมีเครื่องหมายบวก ตรวจด้วย Python/NumPy โดยรวมจุดที่มีพิกัดตรงกันทุกค่า ไม่ได้ซ่อม mesh

ผลนี้ยืนยันโครงสร้าง mesh ตามการตรวจข้างต้น ไม่ได้ยืนยันว่าไม่มีผิวตัดกันเองทั้งหมด หรือยืนยันผล slicing ความแข็งแรงและการประกอบ

| ไฟล์/ชิ้น | ขนาดตามแกนแบบ X × Y × Z (มม.) | สถานะ |
|---|---|---|
| Tub TPU | 190.523 × 217.261 × 54 | รอแก้แบบก่อนพิมพ์จริง |
| Lid TPU | 176 × 174 × 2 | mesh ผ่าน แต่รอให้ layout ตัวถังจบ |
| Wheel hub PETG | 16 × 44 × 44 | พิมพ์ 1 ชิ้นทดลองสวมเพลาจริง |
| Wheel tyre TPU | 16 × ≈64 × ≈64 | พิมพ์ 1 ชิ้นทดลองคู่กับดุม |
| Hall post PETG | 4 × 8 × 36 | พิมพ์ได้ แต่ยืนยันตำแหน่งเซนเซอร์หลัง layout จบ |
| Hinge block PETG L/R | 54 × 40 × 14 ต่อชิ้น | ควรแก้เนื้อรอบรูบานพับก่อนผลิตใช้งานจริง |
| Carrier inner PETG | 20 × 14 × 12.5 | พิมพ์ทดลองร่วมกับบานพับและ insert จริง |
| Carrier outer PETG | 16 × 14 × 12.5 | พิมพ์ทดลองร่วมกับบานพับและ insert จริง |

STL อยู่ในแกน Fusion: Y ขึ้น ต้องหมุนและวางชิ้นงานให้เหมาะสมก่อนสไลซ์ ขนาดในตารางแปลงเป็นแกนแบบแล้ว

## จุดที่ยังไม่ผ่าน

1. **ตัวถังยังไม่มีรูน็อตยึดมอเตอร์ขับ** `build_robot_v4.py` สร้างผนังและรูเพลา Ø8 เท่านั้น ยังต้องวัดรูยึด บ่าหน้า และความยาวเพลาของ JGA25-370 ตัวจริง พร้อมกำหนดวิธีกันดุมเลื่อนตามแกน
2. **อุปกรณ์ภายในเป็นกล่องแทนขนาด** ยังไม่มีที่ยึดแบต ESC ESP32 และ DRV8871 ที่สร้างในตัวถัง ต้องกำหนดที่ยึด การเดินสาย และจุดเข้าถึงตัวตัดไฟ รวมถึงรูยึดฐานมอเตอร์อาวุธเข้าตัวถัง ก่อนส่งผลิต
3. **layout และการกระจายน้ำหนักยังค้าง** `STATUS.md` ระบุว่าล้อหลังรับน้ำหนักประมาณ 5% และต้องลองย้ายแบตไปท้าย จากนั้นตรวจ interference และจำลองซ้ำ งานนี้อาจเปลี่ยนตัวถังและที่ยึดภายใน จึงควรรอพิมพ์ถาดกับฝา
4. **บานพับมีเนื้อบาง 0.4 มม.** knuckle อยู่ที่ y=100…104 และสูงถึง z=16.5 รูแกน Ø3.2 มีศูนย์ที่ y=102, z=14.5 จึงเหลือเนื้อด้านหน้า ด้านหลัง และด้านบนเพียง 0.4 มม. ยืนยันจากหน้าตัด STL จริงของชิ้นขวาที่ x=36 ด้วย ข้อความเดิมใน README ที่ให้พิมพ์บล็อกได้เลยควรถือเป็นความพร้อมด้าน mesh เท่านั้น จากทางส่งแรงที่ระบุไว้ บานพับรับแรงจาก wedgelet จึงควรเพิ่มเนื้อและตรวจระยะแกว่งใหม่ก่อนจัดว่าพร้อมใช้งานจริง
5. **fit ของล้อและบานพับยังไม่ยืนยัน** ดุม OD44 และยาง ID44 เท่ากันใน CAD ไม่มีระยะสวมอัดที่ออกแบบแยกไว้ ส่วนรู D ของดุมใช้รัศมี 2.05 มม. และระนาบแบนห่างศูนย์ 1.55 มม. สำหรับเพลา nominal Ø4 แบนลึก 0.5 มม. รูแกนบานพับ Ø3.2 คู่กับแกน Ø3 เผื่อเส้นผ่านศูนย์กลางเพียง 0.2 มม. ต้องลองกับเครื่องพิมพ์ วัสดุ เพลา และ insert จริง

## ขนาดที่คู่มือเดิมคลาดเคลื่อน

- Tub ใน README ระบุ 176 × 216 × 53 แต่ STL รวมขายึด skirt เป็น **190.523 × 217.261 × 54 มม.**
- Hinge block ใน README ระบุ 54 × 40 × 16.5 แต่ความสูงรวมจริงคือ **14 มม.** (z=4…18); 16.5 เป็นระดับยอด knuckle จากพื้นสนาม
- ถ้าวางถาดตรงตามแกนบนฐาน 220 × 220 มม. ด้านยาวเหลือพื้นที่รวมเพียง 2.739 มม. หรือประมาณ 1.37 มม. ต่อข้างเมื่อจัดกลาง ต้องเช็กพื้นที่พิมพ์ที่ใช้ได้จริงและ brim ใน slicer

## ขั้นตอนถัดไป

วัดอะไหล่จริง → จบ layout และที่ยึดภายใน → เพิ่มเนื้อรอบรูบานพับและตรวจการแกว่ง → พิมพ์ดุม/ยาง/บานพับทดลอง → ตรวจสไลซ์จริง ขนาดฐานพิมพ์ support เวลาและน้ำหนัก → ส่งออก STL ใหม่ → พิมพ์ครบชุด

อ้างอิงภายใน: `build_robot_v4.py` ส่วน chassis, hinged wedgelets และ drive; `STATUS.md` งานค้างข้อ 5–7; `manufacturing/README.md` สถานะพร้อมพิมพ์และหัวข้อต้องวัดของจริงก่อน
