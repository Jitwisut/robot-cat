# จำลองการต่อสู้ V2 vs V3 (R3) vs V4 — 3 ต.ค. 2026

**ประเภทการจำลอง:** แบบลดรูป (reduced-order) + Monte Carlo + แบบจำลองแมตช์ **ไม่ใช่ฟิสิกส์ 3D และไม่มีคนขับจริง**
รันซ้ำได้ด้วย `python3 three_way.py` ผลดิบอยู่ใน `results.json`

- ใช้ตัวจำลองเดิมของ V2 vs R3 (`robot_v3/duel_sim`) ซ้ำ ส่วน V4 ใช้รูปทรงจาก `build_robot_v4.py` และค่าพลังงานใบจาก `v4_design.json`
- **เทียบหุ่นตามที่สร้างจริง ไม่ใช่ตามที่แนะนำให้แก้:**
  - V2 หนัก 1.09 กก. และ R3 หนัก 1.24 กก. ออกแบบไว้ตามเป้าเดิม 1.5 กก.
  - V4 หนัก 1.89 กก. ออกแบบตามกติกาใหม่ 2 กก.
  - R3 ยังไม่ได้ใส่ skirt จึงแยกแสดง "R3 + skirt" เป็นอีกแถว
- **พื้นสนามเป็นพลาสติก/กระเบื้อง:** ทุกคันใช้แรงเสียดทาน μ 0.4–0.8 เท่ากัน (ตัวจำลองเดิมใช้ 0.6–1.0)
- **แรงยกของ V2** ใช้ค่าจากการคำนวณก้านต่อจริง 44–80 N (`exports/v2_linkage_2026-09-30`) แทนช่วงเดา 30–150 N แบบเดิม

เมื่อใส่ค่าตั้งต้นเดิม ตัวจำลองต้องให้ผลตรงกับ `robot_v3/duel_sim/results.json`:

| V2 มุดใต้ข้าง R3 ได้ | 0.940 | 0.940 |

ตรงกันทุกค่า หลังจากนั้นจึงเปลี่ยนเป็นค่าแรงเสียดทานของพื้นสนามใหม่

## ข้อมูลพื้นฐานของแต่ละคัน

| | V2 | R3 | V4 |
|---|---:|---:|---:|
| มวล | 1.09 กก. | 1.24 กก. | 1.89 กก. |
| เวลาหมุนตัว 90° (ใช้แบบจำลองการเลี้ยวเดียวกัน, μ 0.6) | **0.20 วิ** | 0.45 วิ | 0.36 วิ |
| ความสูงขอบหน้า | ใบตัก 2.1 มม., ลิ่มข้างแตะพื้น 0 มม. (ตอนกระแทก) | 0.5–1.5 มม. | wedgelet 0.5–1.5 มม., ช่องใบ 2.5 มม. |
| ความสูงขอบข้าง/ท้าย | 0–6 มม. | การ์ด 6 มม. + ยางที่มุมเปิดโล่ง | **4 มม.** (ใต้พื้นถาด) |
| อาวุธ | lifter ยกปลายได้ 44 มม. | ลิ่มยก 36 มม. | beater ≈57 J |

- **V4:** ตอนหมุนครบ 90° อัตราหมุนยังอยู่ที่ประมาณ 8.7 rad/s จึง**ไม่ถึง**ขีดจำกัดอัตราเลี้ยว 12 rad/s (690°/s) ที่ตั้งไว้ในเฟิร์มแวร์
- **R3:** รายงานเดิมได้ 0.39 วิ ที่ต่างกันเพราะรอบนี้ใช้ μ 0.6 แทน 0.8 ไม่ได้ขัดกัน

**มีใครพลิก V4 ได้ไหม?** ต้องเอียง V4 ถึง 70° คือยกขอบข้างขึ้นประมาณ **165 มม.** แต่ V2 ยกได้แค่ 44 มม. และ R3 ได้ 36 มม.
**จึงไม่มีคันไหนพลิก V4 ได้** ทำได้แค่ยกด้านข้างให้ล้อลอย ซึ่งนับเป็นการคุมเกม ไม่ใช่ชนะเด็ดขาด (V4 ขับกลับหัวได้อยู่แล้ว)

## ผลแต่ละสถานการณ์ (สมมติฐานหลัก)

ตัวเลขในตารางคือโอกาสต่อการปะทะ 1 ครั้ง:
- **ทำให้หมด** = อีกฝ่ายขยับต่อไม่ได้
- **คุม** = ยกอีกฝ่ายลอย ดันชนะ หรือตีโดนแต่อีกฝ่ายไม่คว่ำ
- เลขที่เหลือไปจนครบ 100% คือ "ไม่มีใครได้เปรียบ"

**V4 vs V2**

| **V2 ชนข้าง/ท้าย V4** | 0% | 0% | **98%** |

- ใบ V4 ตีใบตักของ V2 แล้วทำให้ lifter ของ V2 พังได้ประมาณ 39% ต่อการชนหน้า 1 ครั้ง
- **แต่ lifter พังแล้ว V2 ก็ยังคุมได้เท่าเดิม** เพราะลิ่มข้างของ V2 เป็นแบบติดตายสูง 0 มม. ยังมุดใต้ขอบ 4 มม. ของ V4 ได้ ทำให้ล้อ V4 รับน้ำหนักน้อยลงและแพ้การดัน
- ตีแล้ว V2 ลอยเฉลี่ยประมาณ 0.75 ม.
- V2 วิ่งกลับหัวไม่ได้ ถ้าคว่ำคือแพ้ทันที

- สัดส่วนการชนหน้าอยู่ที่ 30–70% ส่วนที่เหลือเป็นการชนข้าง/ท้าย แบ่งให้คันที่เลี้ยวเร็วกว่าได้มากกว่า (ข้าง 70%, ท้าย 30%)
- ถ้าทำให้อีกฝ่ายหมดได้ แมตช์จบทันที ไม่อย่างนั้นใช้แต้มคุมเกมตัดสิน

| **V4 vs R3** | **V4 77% / 94% / 100%** | R3 0–8% | ชนะด้วยแต้ม เพราะ R3 คว่ำแล้วยังขับได้ แค่เสียอาวุธ |

### กรณีมองแง่ร้ายสำหรับ V4

สมมติให้ใบส่งพลังงานได้น้อยลงมาก:
- ชนตรงๆ ส่งพลังงาน 10–25%
- ตอนที่อีกฝ่ายมุดใต้ wedgelet แล้ว เหลือแค่ 1–5%
- คู่ต่อสู้ตกลงมาคว่ำแค่ 10–30%
- ต้องลอยเกิน 0.6 ม. จึงนับว่าตีโดน

| คู่ | V4 ชนะ (ต่ำสุด / กลาง / สูงสุด) | คู่ต่อสู้ชนะ |
|---|---|---|
| V4 vs V2 | 12% / 23% / 41% | **V2 57% / 73% / 81%** |
| V4 vs R3 | 34% / 46% / 58% | R3 33–39% |

### V4 + skirt บานพับ (เพิ่ม 4 ต.ค. ตามที่สร้างใน CAD แล้ว)

ใช้ขอบข้างและขอบท้ายของ V4 ≈0 มม. (σ 0.3) จาก skirt ที่ห้อยแตะพื้น ส่วนการชนหน้าเหมือนเดิม

| คู่ | สมมติฐานหลัก: V4 ชนะ | มองแง่ร้าย: V4 ชนะ | มองแง่ร้าย: คู่ต่อสู้ชนะ |
|---|---|---|---|
| V4 + skirt vs V2 | 89% / 99% / 100% | 14% / 27% / 49% | **V2 44% / 66% / 79%** |
| V4 + skirt vs R3 | 95% / 100% / 100% | **45% / 62% / 83%** | R3 10–34% |

**ผลของ skirt:**
- **เจอ R3:** ช่วยชัดเจน ในกรณีมองแง่ร้าย V4 พลิกจากสูสีกลายเป็นได้เปรียบ (46% → 62%)
- **เจอ V2:** ช่วยน้อย (V2 ชนะลดจาก 73% เหลือ 66%) เพราะ V2 ยังได้เปรียบจาก**การชนหน้า** ลิ่มข้างของ V2 ที่แตะพื้น 0 มม. มุดใต้ wedgelet ของ V4 (0.5–1.5 มม.) ได้
- **ขั้นต่อไปที่ควรแก้** คือทำ wedgelet ให้แตะพื้นด้วย เช่นแบบบานพับ

### V4 ตามที่สร้างตอนนี้: skirt บานพับ + wedgelet บานพับ (4 ต.ค.)

ขอบหน้าช่วง wedgelet ≈0 มม. (σ 0.3) ส่วนช่องใบยังสูง 2.5 มม. และขอบข้าง/ท้าย ≈0 มม. (σ 0.3)

| คู่ | สมมติฐานหลัก: V4 ชนะ | มองแง่ร้าย: V4 ชนะ | มองแง่ร้าย: คู่ต่อสู้ชนะ |
|---|---|---|---|
| **V4 ตอนนี้ vs V2** | 90% / 99% / 100% | **42% / 55% / 71%** | V2 21% / 32% / 40% |
| **V4 ตอนนี้ vs R3** | 96% / 100% / 100% | **89% / 97% / 100%** | R3 0–3% |

**ผลของ wedgelet บานพับ:**
- **เจอ R3:** V4 ชนะแทบทุกแมตช์แม้ในกรณีมองแง่ร้าย เพราะ R3 แทบมุดใต้ขอบหน้าไม่ได้ (โอกาสที่ R3 คุมการชนหน้า ลดจาก 58% เหลือ 11%)
- **เจอ V2:** กรณีมองแง่ร้ายพลิกจาก V2 ชนะ 66% เป็น **V4 ชนะ 55%** แต่ลิ่มข้างของ V2 ที่สูง 0 มม. ยังมุดใต้ขอบที่สูง ≈0 มม. ได้บางครั้ง จึงยังไม่ขาดลอย

**ตัวเลขนี้ขึ้นอยู่กับสมมติฐานว่าแผ่นบานพับแตะพื้นจริง** (σ 0.3 มม.) ถ้าแผ่นเด้งหรือถูกเศษบนพื้นค้ำไว้ ผลจะแย่ลงไปทางแถว "V4 + skirt" ด้านบน ต้องวัดความสูงปลายบนพื้นสนามจริง

**ผลพลิกได้ทั้งหมด** ขึ้นอยู่กับคำถามเดียว: **ใบของ V4 ยังตีได้แรงไหม ตอนที่ลิ่มต่ำของคู่ต่อสู้มุดเข้าใต้ wedgelet ไปแล้ว**
ถ้าตีได้แรง V4 ชนะทั้งสองคันอย่างชัดเจน ถ้าตีได้เบา V2 ซึ่งเลี้ยวเร็วกว่าเกือบ 2 เท่าและเข้าใต้ขอบข้าง 4 มม. ของ V4 ได้แทบทุกครั้ง จะชนะด้วยแต้มคุมเกม

## อันดับ

| สมมติฐาน | อันดับ |
|---|---|
| หลัก | **V4 > R3 > V2** |
| มองแง่ร้ายสำหรับ V4 (V4 แบบเดิม wedgelet ยึดตาย ไม่มี skirt) | ชนะวนกันแบบเป่ายิงฉุบ: V2 ชนะ V4, R3 ชนะ V2, V4 สูสีกับ R3 |
| **มองแง่ร้ายสำหรับ V4 (V4 ตอนนี้: skirt + wedgelet บานพับ)** | **V4 > R3 > V2** (V4 ชนะ V2 55%, ชนะ R3 97%) |

## สิ่งที่ควรแก้ใน V4 (จากผลนี้)

1. **(ทำแล้ว 4 ต.ค. — ดูหัวข้อ V4 + skirt ด้านบน) จุดอ่อนใหญ่ที่สุดคือขอบข้างและขอบท้ายสูง 4 มม.** จำลองแยกเฉพาะ V4 ว่าคู่ต่อสู้มุดใต้ข้างได้กี่ %:

   | ขอบข้าง/ท้ายของ V4 | V2 มุดได้ | R3 มุดได้ |
   |---|---:|---:|
   | ตอนนี้ (4 มม.) | 98% | 100% |
   | skirt ติดตาย 1 มม. | 51% | 42% |
   | **skirt บานพับ ห้อยแตะพื้น** | **24%** | **7%** |

   **แนะนำแบบบานพับแตะพื้น** เพราะแบบติดตาย 1 มม. ยังแพ้ลิ่มของ R3 ที่ต่ำ 0.5–1.5 มม. เกือบครึ่ง ส่วนแบบบานพับยังแพ้ลิ่มข้างของ V2 ที่แตะพื้นอยู่ 24%
   **ต้องเช็กน้ำหนักด้วย:** skirt หนักประมาณ 50–60 กรัม แต่ตอนนี้เหลือเผื่อแค่ 110 กรัม
2. **(ทำแล้ว 4 ต.ค. — ดูหัวข้อ V4 ตามที่สร้างตอนนี้) ทำ wedgelet ให้แตะพื้นจริง** เช่นแบบบานพับ เพื่อให้ขอบต่ำกว่าลิ่มของ R3 (0.5–1.5 มม.) ลดจังหวะที่อีกฝ่ายมุดเข้าใต้ ซึ่งเป็นตัวแปรที่พลิกผลได้มากที่สุด
3. **ทดสอบของจริง:** ให้ใบ V4 ตีลิ่มเหล็กที่ต่ำ 1 มม. ในกล่องปิด แล้ววัดว่าลิ่มกระเด็นสูงแค่ไหน ผลนี้จะบอกว่าสมมติฐานหลักหรือแบบมองแง่ร้ายใกล้ความจริงกว่า

## ข้อจำกัด

- ไม่มีฟิสิกส์ 3D ไม่มีการเด้ง การหมุนกลางอากาศ ผนังสนาม หรือหลุม
- ไม่ได้คิดความเสียหายสะสม ความร้อน แบตหมด หรือคนขับพลาด
- ไม่ได้คิดความแข็งแรงของ V4 เอง เช่น แผ่นตั้งยึดใบบนบล็อก TPU, ลูกปืน และแรงสะท้อนกลับจากใบ ซึ่งยังไม่มี FEA
- R3 กับ V2 ไม่ได้ปรับให้ใช้น้ำหนักเต็ม 2 กก. จึงเป็นการเทียบหุ่นที่มีอยู่จริง ไม่ใช่เทียบแบบที่ดีที่สุดในแต่ละแนวคิด
