# การจำลองแรงชนเบื้องต้นของ `robot2`

วันที่ 24 ก.ย. 2026 — โมเดลฐานคือ `robot2_items_1_3_2026-09-24.f3d` และสำเนาใน Fusion ชื่อ `robot2_sim_2026-09-24`.

## ขอบเขต

ผลนี้คำนวณด้วยแบบจำลองคานไฟไนต์เอลิเมนต์ 1 มิติของใบ lifter และแบบจำลองการชน 1 องศาอิสระที่มีการครากแบบ bilinear **ยังไม่ใช่** Fusion Static Stress / Dynamic Event Simulation ของหุ่นทั้งตัว และไม่ใช่ผลทดสอบชนจริง. ใช้คัดกรองจุดเสี่ยงและเลือกกรณีที่จะส่งไปทดสอบเต็มรูปแบบ.

สมมติให้ใบกว้าง 62 มม. ยึดแน่นที่ y=74 มม. และถูกชนแนวดิ่งที่ปลาย y=112 มม. วัสดุใน CAD เป็น 6061 โดยใช้ E=68.9 GPa และค่าคราก 275 MPa; สภาพอบแข็งของวัสดุจริงยังไม่ได้ยืนยัน. ใช้มวลเทียบเท่า 1.5 กก. ชนกับคู่ต่อสู้แข็ง ไม่มีการสูญเสียที่หน้าสัมผัส และใช้ความแข็งหลังคราก 2% ของความแข็งเริ่มต้น. จำลองกรณีหน้าสัมผัสเต็ม 62 มม. และเฉพาะแถบ 10 มม. เพื่อดูความไวต่อบริเวณสัมผัส. การยึดปลายหลังแบบแน่นอาจแข็งกว่าบานพับจริง.

\*ค่าเสียรูปถาวรเป็น **ตัวแทนจากสปริง bilinear** ไม่ใช่แผนที่ plastic strain จาก FEA 3 มิติ. ค่า Von Mises ที่ใบมาจากความเค้นดัดสูงสุดของคานในช่วงยืดหยุ่น; เมื่อคราก การกระจายความเค้นจริงต้องใช้วัสดุไม่เชิงเส้นและการสัมผัส 3 มิติ. ในไฟล์ผลลัพธ์ `elastic_equivalent_root_bending_MPa` หลังครากเป็นเพียงค่าคำนวณย้อนด้วยสมการยืดหยุ่นและมี `root_stress_model_valid=false`; ห้ามอ่านเป็น Von Mises จริง. ค่า velocity/acceleration เป็นของมวลเทียบเท่าในแบบจำลอง ไม่ใช่ของทุกชิ้นส่วนหุ่น.

แรงที่ใบเริ่มครากในแบบสัมผัสเต็ม ≈1,163 N หรือความเร็วเริ่มคราก ≈1.00 m/s ภายใต้สมมติฐานนี้. ถ้าชนเฉพาะแถบ 10 มม. แรงเริ่มครากลดเหลือ ≈188 N และความเร็ว ≈0.40 m/s. ดังนั้น **พื้นที่สัมผัสมีผลสูงมาก** และห้ามใช้เลขเดียวเป็นเกณฑ์ว่าหุ่นทั้งตัวจะพังที่ความเร็วใด.

ผมทดสอบความไวต่อ **มวลเทียบเท่า** เพิ่มที่ 0.25, 0.62 และ 1.5 กก. (`mass_sensitivity.csv`). สำหรับหน้าสัมผัสเต็มและความเร็วสัมพัทธ์ 1 m/s แรงยอดเปลี่ยนจากประมาณ 476 → 748 → 1,163 N ตามลำดับ; สองกรณีแรกไม่ถึงค่าครากของใบในแบบจำลอง. ค่า 0.62 กก. เป็น reduced mass โดยประมาณของหุ่น 1.05 กก. กับคู่ต่อสู้ 1.5 กก. เมื่อทั้งคู่เคลื่อนที่อิสระ; มวลหุ่นยังเป็นตัวเลข CAD ชั่วคราว. ผลจึงไวต่อสภาพการชนและการจับยึด ไม่ควรถือว่าทุกการชน 1 m/s ทำให้ใบคราก.

## แกน lifter และเส้นทางแรง

แกนเหล็ก Ø6 มม. ช่วงแท่นรอง 67 มม. ยังไม่ระบุเกรด/ค่าครากจริง. ถ้าสมมติเป็นคานรองรับสองปลายและแรงทั้งหมดลงกลางแกน ความเค้นดัด ≈0.790 MPa ต่อแรง 1 N และโก่ง ≈0.000492 มม. ต่อแรง 1 N. เหล็กที่คราก 250 MPa จะเริ่มครากที่ ≈317 N ตามสมมติฐานนี้. ตัวอย่างแรงชน 583 N จากกรณีใบเต็ม 0.5 m/s จะให้ ≈460 MPa **เฉพาะกรณีที่แรงทั้งหมดผ่านแกนกลาง**. การแบ่งแรงจริงผ่านบอส ขายึด และตัวรับใบยังไม่ทราบ จึงยังตัดสินว่าแกนจริงจะครากไม่ได้.

จุดที่ควรออกแบบและทดสอบเพิ่มก่อนประกอบแข่งคือโคนใบ lifter, แกนและบูช, แท่นรองแกนกับน็อต M3, รอยต่อลิ่มกับฐาน, และจุดยึดแบตเตอรี่. หากแรงชนผ่านข้อต่อเซอร์โว ต้องมีตัวรับแรง/stop เชิงกลที่ไม่ปล่อยแรงปะทะเข้าก้านเซอร์โวโดยตรง.

**การตรวจแรงบิดที่บานพับ:** ปลายใบอยู่ห่างแกนหมุน 44 มม. ถ้าไม่มี stop รับแรงไว้ แรงชน 583 N ในกรณี 0.5 m/s ข้างบนเท่ากับโมเมนต์ประมาณ **25.6 N·m** รอบแกน เทียบกับชื่อรุ่นเซอร์โว 40 kgf·cm ซึ่งเท่ากับประมาณ **3.92 N·m** เป็นอัตรา 6.5 เท่า. ชื่อรุ่นเป็นค่าแรงบิดที่ระบุ ไม่ใช่พิกัดทนแรงกระแทก และกลไกจริงอาจถ่ายแรงไปที่จุดอื่น; ตัวเลขนี้จึงเป็นเหตุให้เพิ่ม **hard stop ที่โครง** และวัดเส้นทางแรงจริง ก่อนใช้ servo รับการชน.

**กรณีชนลิ่มหน้าและด้านข้าง:** คำนวณกรอบพลังงาน/แรงเฉลี่ยไว้ใน `front_side_load_envelope.csv` สำหรับ 0.5–3 m/s และระยะหยุด 2, 5, 10 มม. เช่น มวลเทียบเท่า 1.5 กก. ที่ 2 m/s กับระยะหยุด 5 มม. มีพลังงาน 3 J และแรงเฉลี่ย 600 N; แรงสูงสุดอาจมากกว่า. ยังแปลงเป็น Von Mises ของลิ่มหรือแผ่นข้างไม่ได้ เพราะตำแหน่งสัมผัส จุดรองรับ ความแข็งของน็อต/รอยต่อ และระยะหยุดจริงไม่ทราบ. การทำ FEA โดยล็อกลิ่มกับฐานอย่างสมบูรณ์จะให้ความแข็งเกินกว่าชุดน็อตจริง.

## การตรวจความถูกต้องเชิงตัวเลข

- เพิ่มจำนวนชิ้นคาน 40 → 80: ค่าการโก่งปลายเปลี่ยน 0.0113%.
- เทียบความยืดหยุ่น FE กับอินทิกรัลคานอิสระ: ต่าง 0.00377%.
- กรณี 0.5 m/s ที่ยังไม่คราก เทียบแรงสูงสุดกับคำตอบตัวแกว่งมวล–สปริงแบบปิดรูป: ต่าง <1%; พลังงานกลับใกล้พลังงานเริ่มต้น.
- รันความไวต่อความเร็ว 0.5, 1, 2, 3 m/s และความกว้างสัมผัส 62/10 มม.; ไฟล์เวลาทุกกรณีมี F, displacement, velocity, acceleration และ plastic offset.

## สถานะ Fusion Simulation

เปิดสำเนา `robot2_sim_2026-09-24` ใน Fusion และบันทึกสำเร็จแล้ว. การเรียกคำสั่ง **New Simulation Study** ผ่าน Fusion MCP ทำให้แอปปิดตัว **สองครั้ง**. เปิดเอกสารกู้คืนขึ้นมาเพื่อตรวจซ้ำ: ใน Design workspace โมเดลและ `DesignProductType` แสดงปกติ แต่เมื่อสลับไป Simulation workspace แคนวาสว่างเปล่าและ Fusion API รายงาน `activeProduct = None` แม้ `activeDocument` ยังเป็นสำเนาเดิม. หลังเหตุขัดข้อง log ยังรายงาน `No active viewport` และ `There is no active document` ขณะปิดตัว; log ไม่ระบุสาเหตุรากที่ยืนยันได้. จึงหยุดเรียกคำสั่งที่ทำให้แอปปิดซ้ำ และคืนหน้าจอไปที่ Design workspace โดยโมเดลยังแสดงอยู่. **ยังไม่ได้สร้างหรือ Solve Study ใน Fusion** จึงไม่มีผล 3D von Mises, displacement, plastic strain, velocity/acceleration ของหุ่นทั้งตัว. ไฟล์ `robot2` ต้นฉบับและ F3D สำรองก่อนทดลองยังอยู่. ตามเอกสาร Autodesk, Dynamic Event Simulation ให้ผลทั้งห้าประเภทและใช้โทเคน; Linear Static Stress ใช้คัดกรองความเค้น/การโก่งและรวมอยู่ใน subscription. ก่อนรันเต็มรูปแบบต้องระบุเกรดวัสดุจริง, รูปแบบการยึด, contact, มวลคู่ต่อสู้, ความเร็ว และทิศชน.
