# คัดกรองแรงชนที่อาจทำให้ `robot2` เสียรูป

> **ข้อมูลประวัติก่อนแก้แบบ 1–3:** การคำนวณแกนในเอกสารนี้ใช้วัสดุ/การยึดรุ่นเก่า. สำหรับรุ่นที่แก้แล้วให้ดู [ผลจำลองแรงชนเบื้องต้น](impact_sim_2026-09-24/README.md) ซึ่งระบุแกนเหล็กและกรณีชนหลายความเร็ว.

ตรวจวันที่ 2026-09-24 จาก `robot2` ใน Fusion แบบ **ลิ่ม + lifter**. ตัวเลขนี้เป็นการคำนวณคานอย่างง่ายจากรูปทรงและวัสดุที่กำหนดใน CAD ไม่ใช่ Dynamic Event Simulation, การทดสอบหุ่นจริง หรือค่าแรงที่ทำให้หุ่นทั้งตัวพัง. ไฟล์ตัวเลขที่ทำซ้ำได้คือ `impact_screening_2026-09-24.json`; โค้ดอยู่ที่ `../fusion_scripts/impact_screening.py`.

## ข้อมูลจาก CAD

- แกน lifter: Ø6 มม., Aluminum 6061, ระยะระหว่างกึ่งกลางแท่นรอง 67 มม.
- ใบตัก: กว้าง 62 มม., ปลายที่ Y=112 มม., โคนด้านหน้าบอสที่ Y=74 มม., หนาตามหน้าตัดราว 3.94 มม. ที่โคนและ 2.7 มม. ที่ปลาย.
- วัสดุที่ Fusion กำหนดให้ทั้งแกนและใบตักมี `Yield Strength = 275000 kPa = 275 MPa`. นี่เป็นค่าของวัสดุในซอฟต์แวร์; ยังไม่ใช่ผลรับรองเกรด/สภาพชิ้นงานที่ซื้อจริง.
- จุดยึดลิ่มเข้าตัวถังยังไม่มีเส้นทางแรงเชิงกลที่ยืนยันได้. เซอร์โว ก้านต่อ บูช/แบริ่งและสต็อปยังเป็นแบบเผื่อพื้นที่หรือยังไม่ออกแบบ. ทุกกลุ่มมี joint = 0. ดังนั้นยังไม่มีเงื่อนไขสมบูรณ์สำหรับหาค่าเสียหายของหุ่นทั้งตัว.

## ผลคำนวณการเริ่มคราก ไม่ใช่การหัก

| ชิ้นส่วน/กรณีอุดมคติ | แรงที่คำนวณได้เมื่อเริ่มคราก |
|---|---:|
| แกน Ø6 มม. รองรับสองปลาย รับแรงจุดกลาง | **348 N** |
| แกนเดียวกัน รับแรงกระจายสม่ำเสมอตลอดช่วง | **696 N** |
| ใบตักยึดแข็งที่ Y=74 มม. รับแรงปลายเต็มความกว้าง 62 มม. | **1,163 N** |
| ใบตักยึดแข็ง รับแรงปลายเฉพาะแถบกว้าง 10 มม. แบบแถบคานแยก | **188 N** |

แกนใช้ `σ = 32M/(πd³)`, โดย `M = FL/4` สำหรับแรงจุดกลาง หรือ `M = FL/8` สำหรับแรงกระจาย. ใบตักใช้ `σ = 6FL/(bt²)` และคำนวณหน้าตัดตาม profile จริงของ CAD ตลอด Y=74–112 มม. ตั้ง `σ = 275 MPa` เพื่อหาจุดเริ่มเสียรูปถาวรตามค่าของ Fusion. การรองรับจริง, การกระจายแรงจากบอส, ระยะหลวม, จุดชน, ก้านต่อและการหมุนที่บานพับล้วนต่างจากคานอุดมคติ; ค่าเหล่านี้จึง **ไม่ใช่แรงรับประกันหรือแรงใช้งานที่ปลอดภัย**. ค่าแถบ 10 มม. เป็นเพียงขอบเขตสมมติ ไม่ได้จำลองการแผ่แรงในแผ่น 3 มิติ.

## ตัวอย่างแรงเฉลี่ยของการชน

ใช้พลังงาน `E = ½mv²` และแรงเฉลี่ย `F = E/s` สำหรับมวลชนสมมติ 1.5 กก. แรงยอดจริงอาจสูงกว่าแรงเฉลี่ย; มวลเชิงประสิทธิผลและระยะหยุดจริงยังไม่ทราบ.

| ความเร็วชน | หยุดใน 10 มม. | หยุดใน 5 มม. | หยุดใน 2 มม. |
|---|---:|---:|---:|
| 1 m/s | 75 N | 150 N | 375 N |
| 2 m/s | 300 N | **600 N** | 1,500 N |
| 3 m/s | 675 N | 1,350 N | 3,375 N |

ถ้าแรงชนผ่านแกน lifter จริง กรณี 2 m/s และระยะหยุด 5 มม. อยู่ในช่วงที่การคำนวณแกนอย่างง่ายเริ่มครากได้. ถ้าแรงลงลิ่มแทน ผลจะขึ้นกับน็อต/รอยต่อที่ยังไม่ได้ระบุ จึงหาค่าแรงทำลายทั้งหุ่นไม่ได้. การที่ชิ้นหนึ่งเริ่มครากไม่ได้แปลว่าหุ่นหยุดทำงานทันที และชิ้นอื่นอาจเสียก่อน.

## ขั้นต่อไปเพื่อได้ค่าแรงทำลายที่เชื่อถือได้

1. เพิ่มตัวยึดลิ่ม, รู/น็อตจริง, เซอร์โวและก้านต่อ, บูช/แบริ่งแกน, สต็อป และ joint. แก้การซ้อนทับแกนกับลิ่มก่อน.
2. เลือกกรณีชนอย่างน้อยหน้าเต็ม, จุดที่ปลาย lifter และชนด้านข้าง พร้อมมวล/ความเร็ว/ตำแหน่งชน/ระยะหยุดที่ทีมจะใช้เป็นโจทย์.
3. ทำ Static Stress เพื่อคัดกรองเส้นทางแรงและ Dynamic Event Simulation สำหรับการชนจริง พร้อม contact และ mesh convergence. Autodesk ระบุว่า Static Stress ไม่คิดความเฉื่อยของการชน; Event Simulation ใช้กับเหตุการณ์กระแทก. [Static Stress](https://help.autodesk.com/view/fusion360/ENU/?contextId=SIM-STATIC-STRESS-ANALYSIS), [Dynamic Event Simulation](https://help.autodesk.com/cloudhelp/ENU/Fusion-Simulate/files/SIM-EVENT-SIM-STUDY-CONCEPT.htm).
4. ทดสอบต้นแบบที่ประกอบจริงในสถานที่ป้องกันเหมาะสม วัดแรง/ความเร่งและดูการงอ การคลายของน็อต การหลุดของแกน และการทำงานหลังชน. นำผลกลับมาแก้สมมติฐานของ Simulation.

**สถานะการทดสอบครั้งนี้:** ตรวจ CAD สดและคำนวณคัดกรองแล้ว; ยังไม่ได้ทำ FEA หรือชนหุ่นจริง. Fusion ระบุว่า Event Simulation เป็น cloud solve ที่ใช้ 6 Flex tokens ต่อ study จึงไม่ได้เริ่มการวิเคราะห์ที่มีค่าใช้จ่ายโดยไม่มีแบบประกอบและเงื่อนไขชนครบ. [Autodesk token rates](https://help.autodesk.com/view/fusion360/ENU/?contextId=CC-SIMULATION).
