# ROBOT V3 — สถานะ 24 ก.ย. 2026

**สถานะ: CAD และการคัดกรองเบื้องต้นเสร็จ; ยังไม่ผ่านอนุมัติผลิตหรือแข่ง.** ผู้ใช้สั่งเริ่มตาม optional phase หลังจาก V2 (`robot2`) บันทึกแล้วและมีรายงานสถานะวิศวกรรม. V2 ยังมีปัญหาทางวิศวกรรมและงบที่เปิดอยู่; V3 จึงเป็นการศึกษา CAD/Simulation เท่านั้น. ไม่แก้หรือทับไฟล์ V1/V2 และไม่ได้ซื้อชิ้นส่วน.

## ผลและขอบเขต

- สถาปัตยกรรมต่างจาก V1 ใบหมุนแนวตั้งและ V2 ลิ่ม + lifter สองล้อ: V3 ใช้ tub อะลูมิเนียมเตี้ย, 4WD, plow เต็มหน้าที่ตั้งใจให้ถอดเปลี่ยนได้เมื่อออกแบบรูยึดแล้ว, ปากจับอยู่หลังแนวชน, และฝาเปิดบริการแยกสองส่วน.
- อาวุธเป็น clamp/lifter: แผ่นก้ามบน, ปลายงุ้ม, ฟันเหล็กเปลี่ยนได้ 3 ซี่, แขนถ่ายแรง, ก้านต่อสองข้าง, servo envelope และ hard stop. ข้อต่อหลักเปิด 0°, 25°, 55° ได้ และการตรวจ interference ไม่พบการชนกับชิ้นส่วนอื่นที่สามตำแหน่งนี้. ก้านต่อยังเป็น geometry เบื้องต้นและยังไม่มีสมการ four-bar/แรงบิดจริง.
- มวล CAD **944.124 g ไม่ใช่น้ำหนักผลิตจริง**. มอเตอร์ แบตเตอรี่ เซอร์โว และวงจรเป็นปริมาตรเผื่อด้วยวัสดุแทน; นอต/สาย/ฮับ/บูชยังไม่ครบ. เปรียบเทียบน้ำหนักกับ V2 โดยตรงไม่ได้.
- การคำนวณ stress/displacement เป็น **คาน 1 มิติของ plow ที่จับโคนแน่นในอุดมคติ**. ยังไม่มี 3D FEA ของชุดยึด, การเสียรูปพลาสติกจริง, ความเร็วหรือความเร่งจากการชน. Fusion Simulation ของ V2 ยังสร้าง Study ไม่สำเร็จเพราะแอปปิดตัวซ้ำ; ไม่ได้อ้างว่ามี Study/Solve ของ V3.
- V3 ไม่มีรูยึด plow จริง, mount มอเตอร์/เซอร์โวจริง, linkage pin/bushing จริง หรือการยืนยัน clearance สาย/แบต. ยังไม่มี BOM ราคาส่งถึงไทยครบและไม่มีข้อมูลของที่ผู้ใช้มี. **ยังยืนยันยอดรวมโครงการ ≤5,000 บาทไม่ได้.** V2 ยังเป็นตัวหลักสำหรับการผลิตจริงตามโจทย์.

## งานที่ต้องทำต่อก่อนตัดสินใจผลิต

1. ยืนยันรุ่น V1/V2 ที่ต้องใช้เทียบ, น้ำหนักแข่ง/กติกา, ของที่มี และเครื่องมือ/บริการของคณะพร้อมค่าใช้จ่าย.
2. ปิด BOM V2 ทุก SKU รวมค่าส่ง วัสดุผลิต นอต สาย ชาร์จเจอร์ และเงินสำรองให้รวมไม่เกิน 5,000 บาท; ถ้าไม่ผ่าน ต้องเปลี่ยนสถาปัตยกรรมหรือยืนยันชิ้นส่วนที่มีจริง.
3. สำหรับ V3 ให้ใช้ไฟล์ STEP/ชิ้นจริงแทน envelope, ออกแบบรูและเส้นทางแรงของ plow, ชุดยึด 4WD และข้อต่อ/stop ของปากจับก่อนทำ 3D FEA.
4. ทดสอบพลังงาน/ทิศชนเดียวกันกับ V1/V2, วัดกระแสขับ/อุณหภูมิ/แบตและ failsafe, ชั่งมวลจริง, ทดสอบซ่อมและเปลี่ยน plow ตามเวลาที่กำหนด. ยังไม่มีข้อมูลทดสอบจริงให้ประกาศว่า V3 ดีกว่า.

## R2 — แก้อาวุธเพื่อสู้ robot2 (24 ก.ย. 2026)

ไฟล์ใหม่: `ROBOT_V3_R2_Competition.f3d` / `.step` สร้างจาก `build_robot_v3_r2.py`. ไฟล์ R1 เดิมไม่ถูกแก้.

| รายการ | R1 | R2 |
|---|---|---|
| ปลาย plow เหนือพื้น | 1–3 มม. (อะลูมิเนียม) | **0.5–1.5 มม.** แผ่นขอบเหล็กเปลี่ยนได้ `Replaceable_Hardened_Steel_Edge` ปลายหนา 1 มม. |
| ความกว้าง plow | 120 มม. (ล้อหน้าโผล่ ±61–82) | **168 มม.** ปีกบังหน้าล้อเฉพาะช่วงล่าง (สูง ≈15 มม. จากพื้นที่ปีก; ยางสูง 42 มม.) ห่างล้อ 7 มม. — ชิ้นที่ไต่ขึ้น ramp ยังโดนครึ่งบนของยางได้ |
| ระยะเทียบ robot2 | ใต้ใบตัก 2.8 มม., ขอบฐานข้าง 0 มม. | ใต้ใบตัก **4.3 มม.**, ลิ่ม 3.5 มม., ขอบฐานข้าง **1.5 มม.** |
| ก้ามเปิดสุด | 55° ฟันสูง 54.5 มม. | **75° ฟันสูง 70.3 มม.** (ยังต่ำกว่าผนังข้าง robot2 78 มม. — งับด้านข้างไม่ได้; เปลี่ยนแค่ joint limit ยังไม่ได้คำนวณเซอร์โว/ก้านต่อใหม่) |
| ความลึกคอก้าม | ≈30–35 มม. จากฟันถึง bulkhead | ≈30–35 มม. (ไม่เปลี่ยน) |
| ช่องก้ามตอนปิด | — | ฟันห่างผิว plow ≈1.6 มม. |
| มวล CAD (proxy) | 944.1 g | 1,030.9 g (+87 g จากขอบเหล็กและปีก) |

- แก้ plow ทับพื้นถาด (R1 ทับกัน 384 mm³) ให้ใต้ plow อยู่ z=6 ถึง y=82.
- **แก้ข้อมูลเดิม:** การตรวจ interference แบบทุกชิ้นพบ **43 จุดที่มีอยู่แล้วตั้งแต่ R1** — แยกเป็น: ชนกันจริงด้าน packaging 16 จุด, ตั้งใจ (เพลาทะลุล้อ/มอเตอร์/ราง) 12 จุด, ชิ้นซ้อนจากการโมเดล (ก้ามกับปลาย/ฟัน, bolt land/cheek กับ bulkhead, placeholder ก้านต่อ/horn) 15 จุด (ไม่ได้เกิดจาก R2 และไม่เปลี่ยนตามมุมก้าม). ข้อความเดิมว่า "ไม่พบ interference" ตรวจเฉพาะชิ้นก้ามที่ขยับ. จุดสำคัญ: ซองมอเตอร์ขับหน้า 2 ตัวซ้อนกับเซอร์โวก้าม, horn, hinge cheek และก้านต่อ; ซองมอเตอร์หลังซ้อนกับ receiver/UBEC/สวิตช์; shear key ซ้อนมอเตอร์หน้า. **layout ภายในยังจัดวางไม่ได้จริง** ต้องย้ายมอเตอร์/เซอร์โวก่อนผลิต.
- ยังเหมือน R1: ก้านต่อเป็น placeholder, ไม่มีรูยึด, ไม่มี 3D FEA, ESC 8 A/ช่อง ต่ำกว่า stall 2×4.3 A, งบ 5,000 บาทยังไม่ยืนยัน. แผ่นกว้าง 168 มม. ต้องตรวจกับกติกาขนาดเมื่อมีประกาศ.

## R3 — อาวุธลิ่มยก (lifting wedge) + เซอร์โวกลางตัว (25 ก.ย. 2026)

ไฟล์: `ROBOT_V3_R3_Lifter.f3d` / `.step` จาก `build_robot_v3_r3.py`. R1/R2 ไม่ถูกแก้.

**เลือกอาวุธ:** เปลี่ยนก้ามหนีบเป็น **ลิ่มยกกลาง 79 มม.** ขับด้วยเซอร์โว 40 kg ผ่าน crank + pushrod. เหตุผล: ก้ามอ้าได้ 70 มม. แต่ผนังข้าง robot2 สูง 78 มม. จึงงับข้างไม่ได้ ส่วนลิ่มยกไม่ต้องอ้าปาก ใช้ระยะมุดใต้ขอบฐานข้าง 1.5 มม. ที่ R2 ได้แล้ว. **ได้ผลชัดเมื่อเข้าด้านข้าง** (ยกล้อฝั่งใกล้ของ robot2 พ้นพื้น). **ด้านหน้ายังไม่แน่นอน:** ใบตักกลางของ robot2 เป็นข้อหมุนที่มี stop ด้านล่างเท่านั้น การยกจะแค่ดันใบตักขึ้นและกลายเป็นเซอร์โวสู้เซอร์โว; ลิ่มตาย robot2 (|x| 35–80) อยู่หน้าปีกตายของ V3 ซึ่งยกไม่ได้. ไม่เลือกใบหมุน (spinner) เพราะงบ 5,000 บาทยังไม่ผ่าน (รีโมต+receiver+charger 4,747 บาทถ้าต้องซื้อ), กติกายังไม่ประกาศ และ spinner ต้องการสนามปิด.

| รายการ | ค่า |
|---|---|
| ปีก plow ซ้าย/ขวา | ยึดตาย กว้างรวม 168 มม., ขอบเหล็ก, ความสูงปลายเท่า R2 (0.5–1.5 มม.) |
| ลิ่มยกกลาง | กว้าง 79 มม., แกนหมุน Ø6 ที่ (y 80.5, z 13), joint 0–60° ขับได้ใน Fusion |
| ความสูงปลายเมื่อยก | 30° → 19.6 มม., 60° → 35.9 มม. จากพื้น (วัดที่ปลาย; เกิน ~25° ผิวลิ่มเอียงกลับหา V3 ของที่ถูกยกจะไถลเข้าหาแกนและสูงขึ้นน้อยกว่านี้) |
| เซอร์โวหมุน | 0 → 81.8° สำหรับยก 0 → 60° (Repeat 40 kg ระบุ 270°) |
| แรงที่ปลาย (stall 3.92 N·m อุดมคติ) | 519 N @1°, 115 N @30°, 67 N @60° |
| แรงที่ต้องใช้ยกข้าง robot2 1.5 กก. | ≈7.4 N → เผื่อ ≈9× ที่แย่สุด (60°) |
| ท่าพัก | แท็บพักของลิ่มวางแนบผิวปีก (ช่องว่าง 0) เป็น stop จริง; crank กับ pushrod อยู่แนว toggle จึงไม่มีแรงบิดย้อนเข้าเฟือง |

**จัด layout ใหม่:** เพลาล้อหลังย้ายไป y = −60; เซอร์โวนอนตะแคงกลางตัว (x −35…3, y −8…46); แบต y −48…−13; receiver ซ้าย; ESC/UBEC/สวิตช์ขวา; ตัด shear key/bolt land เดิม; ปีกยึดด้วย M3×20 ×4 จากในถาดทะลุ bulkhead เข้ารูต๊าปลึก 12 มม. ในปีก (x ±49.5, ±58.5, z 10 — หัวน็อตอยู่ใต้มอเตอร์หน้า, ผนังเหลือ ≥1.5 มม.); แกนหมุน Ø6 ยาว ±46 เข้ารูตันในปีก — ประกอบ: สอดแกนผ่านลิ่ม → สวมปีกซ้าย/ขวาเข้าแกนทางข้าง → ขันน็อตปีก (ไม่ต้องใช้แหวนล็อก); bulkhead มีร่องให้ pushrod; พื้นถาดตัดหลบส้นลิ่มช่วงกลาง.

**ตรวจ interference ทุกชิ้น 44 bodies ที่ยก 0/15/30/45/60° (crank/pushrod ถูกจัดตามสมการ four-bar แต่ละมุม): 0 จุด** โดยใช้ขนาดเซอร์โวสูงสุดที่ [BBB Shop](https://shop.bristolbotbuilders.com/product/bservo) ประกาศ **56.2×44.5×20 มม.** (หน้า Repeat ไม่ระบุขนาด). ตำแหน่งแกนเพลาในตัวเซอร์โว (y 30, z 18) ยังเป็นค่าประมาณ ต้องวัดของจริงก่อนเจาะ. ใน F3D มีเฉพาะข้อต่อลิ่มที่ขยับได้; crank/pushrod ยังไม่ได้ต่อ joint จึงไม่ตามเมื่อลากใน Fusion. เพลาล้อถูกตัดออกจากโมเดล (เดิมเป็นจุดซ้อนที่ตั้งใจ).

มวล CAD proxy 861.9 g (ยังเป็นชิ้นแทน ไม่ใช่น้ำหนักจริง).

**ยังค้าง:** ตำแหน่งแกนเพลาเซอร์โวต้องวัดของจริง; pin/บูชของ crank-pushrod-clevis ยังเป็น envelope; ตอนยกคู่ต่อสู้ แรงกดจะดันจมูก V3 ลงพื้นและล้อหลังรับน้ำหนักน้อยลง; ESC 8 A/ช่อง < stall 2×4.3 A; ไม่มี 3D FEA; งบ ≤5,000 บาทยังไม่ยืนยัน.

### R3 อัปเดต 25 ก.ย. — ขนาดเซอร์โวจริง, ที่ยึดเซอร์โว, stop บน

- เซอร์โวใช้ขนาดสูงสุด 56.2×44.5×20 มม. จาก BBB Shop (เดิมเผื่อ 42 มม. ในแนวเพลา ซึ่งเล็กกว่าจริง). receiver หมุน 90° ไปที่ x −61…−43, y 11…39.
- ที่ยึดเซอร์โว: แผ่นโฟม 2 มม. ใต้เซอร์โว + สายรัดอะลูมิเนียม 2 มม. ข้ามตัวเซอร์โว ยึดกับเสา 2 ต้นบนพื้นถาด (ไม่รับแรงผ่านหูเซอร์โว).
- **Stop ด้านบนเป็นชิ้นจริงแล้ว:** บล็อกบนปีก (y 74–78.54, สูงถึง z 27) ที่แท็บของลิ่มชนพอดีที่ 60°. ตรวจใน Fusion: 0–59° ไม่ชน, 60° สัมผัส (ปริมาตร 0), 61° ทับ 0.18 mm³ → stop รับแรงก่อนเซอร์โว.
- แท็บพักถูกยึดเข้ากับลิ่มด้วยครีบ 3.5 มม. (เดิมแตะลิ่มแค่เป็นเส้น); ลิ่มเป็น body เดียว.
- ตรวจ interference 46 bodies ที่ 0/15/30/45/59°: **0 จุด**. มวล CAD proxy 863.9 g.

### R3 อัปเดต 25 ก.ย. — ตัดสินใจระบบไฟ/ขับ

**คง 4WD + BBB Dual ESC v2 ตัวเดียว (มอเตอร์ 2 ตัวขนานต่อช่อง ซ้าย/ขวา)** — ไม่ซื้อ ESC เพิ่ม.
- ESC จำกัดกระแส 8 A ต่อช่องในตัว ([BBB Dual ESC v2](https://shop.bristolbotbuilders.com/product/dualv2/)). ผู้ผลิตแจ้งว่า ESC 8 A ของตน "ใช้แข่งจริงที่ 4S แบบ 4WD มอเตอร์ 22 มม. สองตัวต่อ ESC" ([BBB Single ESC v4](https://shop.bristolbotbuilders.com/product/v4/)) — หลักฐานนี้เป็นของรุ่น single v4 ที่ 8 A เท่ากัน ไม่ใช่ dual v2 โดยตรง.
- มอเตอร์ stall 4.3 A @12 V ([BBB 22 mm](https://shop.bristolbotbuilders.com/product/22mmgearmotor/)) → ที่ 3S 11.1 V ≈ 4.0 A/ตัว, 8.0 A/คู่ (พอดีขีดจำกัด); แบตเต็ม 12.6 V ≈ 9.0 A/คู่ → ESC ตัดเหลือ 8 A = แรงบิด stall ≈ 89% ชั่วครู่. ไม่ไหม้ แค่ดันได้น้อยลงเล็กน้อยตอนแบตเต็ม.
- UBEC Hobbywing 5A ตั้ง **7.4 V** (มีตัวเลือก 5/6/7.4 V, 5 A ต่อเนื่อง/15 A ชั่วครู่) เลี้ยงเซอร์โว 40 kg (สเปก 7.4 V) และ ER6 (รับ 4.5–8.4 V). ESC BEC 3.3 V 0.1 A ไม่ใช้เลี้ยง receiver.
- กระแสรวมโดยประมาณ: ขับ ≤16 A + UBEC ขาเข้า ≈3.7 A ต่อเนื่อง ≈ 20 A → แบต 3S ต้องจ่ายต่อเนื่อง ≥25 A; ฟิวส์หลักหลังสวิตช์ ~20 A (ต้องทดสอบจริง).
- แก้ envelope ตามขนาดผู้ผลิต: ER6 43×25×15 (ตั้งตะแคง x −60…−45), UBEC 50×17×10 (x 12…62, y −12…5). ตรวจ interference 0/15/30/45/59°: 0 จุด; 60° สัมผัส stop. มวล CAD proxy 883.0 g.
- ยังต้องทำจริง: วัดกระแส/อุณหภูมิขณะดัน-ติดตาย 10 วินาที, ตั้ง failsafe ของ ER6/ESC ให้หยุดเมื่อสัญญาณขาด.

## จำลองปะทะ robot2 vs R3 (25 ก.ย. 2026)

รายงาน `duel_sim/DUEL_REPORT.md` (reduced-order + Monte Carlo 20,000 รอบ, ไม่ใช่ Fusion Simulation). สรุป: R3 คุมการชนหน้าได้ 96%, ชนข้าง robot2 ยกได้ 89%; แต่ robot2 ชนข้าง R3 มุดใต้ได้ 94% (การ์ดข้าง 6 มม. + ยางเปิดที่มุม) — ใส่ skirt 1 มม. เหลือ 17%. ดันล้วน R3 ชนะ 70% (หนักกว่า 1.24 vs 1.09 kg). robot2 เลี้ยวเร็วกว่า ~2×.

**แก้ข้อมูล:** ระยะมุดใต้ใบตัก robot2 "4.3 มม." ข้างบนคิดจาก robot2 ตั้งตรง. จุดศูนย์ถ่วง robot2 (มวลผู้ผลิต) อยู่หน้าเพลาเพียง ~0.5 มม. จึงโยก: ขณะกระแทก (หน้าคว่ำ) ใบตักสูง 2.1 มม. → R3 มุดได้แค่ 0.6 มม.; ขณะ robot2 ดัน (หน้าเงย) 9.5 มม. → มุดได้ 8 มม.
