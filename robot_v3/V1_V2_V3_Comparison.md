# เปรียบเทียบ ROBOT V1 / V2 / V3

วันที่ 24 ก.ย. 2026. การตั้งชื่อ **ชั่วคราว** จนผู้ใช้ยืนยัน: V1 = `../exports/robot2_vertical_spinner_option.f3d` (แนวใบหมุนแนวตั้ง), V2 = `../exports/robot2_items_1_3_2026-09-24.f3d` และเอกสาร Fusion `robot2` (ลิ่ม + lifter), V3 = `ROBOT_V3_Competition.f3d` (4WD + plow + ปากจับ). ทั้ง V1 และ V2 ยังอยู่ครบ ไม่เขียนทับ. V2 เป็นตัวหลักที่โจทย์กำหนดให้สร้างจริง; V1/V3 เป็นแบบ CAD/จำลองจนกว่าจะอนุมัติการผลิตแยก.

**ข้อควรระวังในการเทียบ:** รูปร่าง V1/V2 บางส่วนถูกซ่อนหรือเป็น envelope, มวล proxy ใช้วัสดุต่างกัน, แบบจำลองการชนรับแรงคนละเส้นทาง. ตัวเลข stress V2 ที่ใบ lifter และ V3 ที่ plow เป็นการคัดกรอง *เฉพาะชิ้นส่วน* ที่แรงภายนอกเท่ากัน ไม่ใช่การทดสอบหุ่นสองคันในสนามเดียวกัน. V1 ยังไม่มีผลชนที่เทียบได้. ยังจัดอันดับความทน/ความเร็ว/โอกาสชนะไม่ได้.

## การทดสอบที่ทำให้เปรียบเทียบได้จริง

1. กำหนดมวลรวมจริงและตำแหน่ง CG ของแต่ละคัน, วัสดุ/เกรด, fastener, จุดยึดและความเร็ว/มุมชนเดียวกัน.
2. ทดสอบด้านหน้า/ด้านข้างที่ 0.5, 1, 2 m/s หรือพลังงานควบคุมที่เท่ากัน โดยใช้แผ่นสัมผัสเต็มและขอบ 10 มม.; วัดแรง, deformation คงค้าง, เวลาเปลี่ยนอะไหล่.
3. ทำ 3D contact FEA ของ plow–bolt–bulkhead และ lifter–shaft–support แล้วเทียบกับ strain/displacement ของชิ้นทดสอบ; ไม่ใช้คานอุดมคติเป็นเกณฑ์ผ่าน.
4. วัดกระแส peak/อุณหภูมิ/ความเร็วของ 2WD และ 4WD บนพื้นสนามจริง; ตรวจ ESC limit และ failsafe. เทียบเงินสดรวมส่งถึงมือและเวลาทำ/ซ่อม.
