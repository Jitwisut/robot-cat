# ROBOT V3 — ความพร้อมผลิตและข้อจำกัดงบ

วันที่ 24 ก.ย. 2026. **ยังไม่พร้อมผลิต** และไม่ได้สั่งซื้อ. โครงการกำหนดเงินสดรวมไม่เกิน **5,000 บาท** โดย V2 เป็นหุ่นจริงหลัก; V1/V3 เป็น CAD/Simulation เท่านั้นจนกว่าจะอนุมัติการผลิตแยก. สถานะงบ V2 หลักอยู่ใน [`../exports/V2_Budget_Gate_2026-09-24.md`](../exports/V2_Budget_Gate_2026-09-24.md).

## การทดสอบงบ 5,000 บาทของ V2 ตัวหลัก

ตัวอย่างร้านไทยที่ตรวจในเอกสาร V2: [RadioMaster Pocket 2,600 บาท](https://www.fpvthai.com/products/%E0%B8%A7%E0%B8%B4%E0%B8%97%E0%B8%A2%E0%B8%B8%E0%B8%9A%E0%B8%B1%E0%B8%87%E0%B8%84%E0%B8%B1%E0%B8%9A-%E0%B8%A3%E0%B8%B5%E0%B9%82%E0%B8%A1%E0%B8%97-radiomaster-pocket-radio-controller-m2), ER6 1,157 บาท, charger 990 บาท = **4,747 บาทก่อนค่าส่งและตัวหุ่น** หากทั้งสามอย่างต้องซื้อ. เมื่อกันสำรอง 500 บาท เป็น 5,247 บาทก่อนมอเตอร์/แบต/โครง. ดังนั้นเส้นทางนี้ยังไม่ผ่านเพดาน และ **ยังไม่มี TOTAL VERIFIED PHYSICAL PROJECT COST**. ต้องยืนยันว่ามีอะไรแล้วจริง หรือปรับชุดควบคุม/อุปกรณ์พร้อมยืนยัน SKU, สเปก, failsafe, ราคาและค่าส่งใหม่. ไม่ใช้ของที่ “วางแผนจะซื้อ” เป็นของที่มี.

## เกณฑ์ปลดล็อก

1. ยืนยันของที่มีและบริการจากคณะพร้อมราคา. ตรวจ SKU/ราคาไทยปัจจุบัน × จำนวน + ค่าส่งทุกช่องทาง + วัสดุ/ค่าแรง + charger + fasteners/wiring/connectors + เงินสำรอง; แถว `?` ต้องหมดก่อนบอกยอดรวม ≤5,000 บาท.
2. ปิดแบบยึดและระบบไฟ V2 ก่อนสร้างจริง. สำหรับ V3 ต้องแก้ทุกหัวข้อในตารางบนและขออนุมัติผลิตแยก; ไม่ให้ V3 แย่งงบ V2 โดยปริยาย.
3. ผลิต subassembly ทดสอบ: plow/joint, 4WD กระแส/อุณหภูมิ, clamp stop, power/failsafe; ทดสอบการชนใน enclosure ควบคุมและชั่งน้ำหนักก่อนลงแข่ง.
