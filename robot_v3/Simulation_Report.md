# ROBOT V3 — Simulation Report / ผลคัดกรอง

วันที่ 24 ก.ย. 2026. **ยังไม่มี Fusion Simulation Study ที่ Solve แล้ว.** ผลที่มีเป็นการคำนวณคาน 1 มิติจากหน้าตัด plow ในไฟล์ CAD และกรณีแรงตั้งฉากกับปลายแผ่น. วัตถุประสงค์คือหาจุดที่ควรออกแบบ/ทดสอบต่อ ไม่ใช่รับรองแรงที่ทำให้หุ่นพัง.

## แบบจำลองและเงื่อนไข

- ใช้รูปหน้าตัดของ `Bolt_On_Full_Width_Plow_6061` จาก `build_robot_v3.py`: ราก y=74 มม., ปลาย y=112 มม., ความหนาเปลี่ยนจาก 17 เป็น 2 มม. วิเคราะห์คาน Euler–Bernoulli, E=68.9 GPa, สมมติค่าคราก 275 MPa สำหรับ 6061-T6 ที่ **ยังไม่ยืนยัน temper ของแผ่นจริง**.
- สมมติรากถูกยึดแน่นสนิทและแรงตั้งฉากลงที่ปลาย. คำนวณทั้งหน้าสัมผัสเต็มกว้าง 120 มม. และแถบ 10 มม.; การใช้แถบ 10 มม. เป็นสมมติฐานคานอิสระ ไม่รวมการถ่ายแรงข้างและ local dent ของแผ่นจริง.
- แรง 583 N เป็นค่าอ้างอิงจาก reduced model V2 กรณีใบ lifter 0.5 m/s; 300/1,163 N เป็น sensitivity. ไม่ใช่แรงชนที่วัดได้จากสนาม. โมเดลไม่รวมสกรู/แท่นยึด/โครง/ล้อ/พื้น/คู่ต่อสู้.

## การตรวจความไวและความถูกต้องเชิงตัวเลข

- อินทิกรัลความยืดหยุ่นด้วย Simpson 40, 80, 160, 320, 640 ช่วง; ค่าความยืดหยุ่นเต็มหน้าที่ 320 เทียบ 640 ต่าง <0.00004%. กรณี 10 มม. เพิ่ม compliance และ stress 12 เท่าในสมมติฐานคานอิสระ.
- ค่าตัวเลขทั้งหมดสร้างใหม่ได้ด้วย `python3 reduced_impact_screen.py`; ผลดิบอยู่ใน `reduced_impact_results.json`/`.csv`.
- การตรวจขนาด F3D และ STEP ทำใน Fusion หลังนำเข้ากลับ: กรอบเท่ากัน 164.06 × 194.04 × 46.06 มม.; ไม่มี mesh convergence ของ 3D FEA เพราะยังไม่มี mesh/Study.

## ผลทั้งห้าประเภทที่ผู้ใช้ต้องการ

| ผล | สถานะปัจจุบัน | ต้องทำเพื่อได้ผลสำหรับทั้งหุ่น |
|---|---|---|
| Von Mises Stress | มีเพียงค่าความเค้นดัดคานของ plow ข้างบน; ไม่มีแผนที่ Von Mises | 3D contact model ใส่ bolt preload/ตำแหน่งชน/วัสดุและตรวจ mesh |
| Displacement | มีเพียงการโก่งปลาย plow ตามคานอุดมคติ | 3D model แสดงส่วนที่โก่งและขยับของ chassis, plow, clamp, mounts |
| Plastic Deformation | **ยังคำนวณไม่ได้**. ค่าคานในตารางยังต่ำกว่า yield ที่สมมติ แต่ไม่ได้ทดสอบการครากของ joint หรือ local indentation | material curve, nonlinear contact, หรือวัดการเสียรูปคงค้างหลังชน |
| Velocity | **ยังคำนวณไม่ได้** สำหรับชิ้นส่วนจาก static beam | Dynamic Event ที่กำหนดมวล/ความเร็ว/เวลา/การสัมผัสและตรวจ energy balance |
| Acceleration | **ยังคำนวณไม่ได้** สำหรับชิ้นส่วนจาก static beam | Dynamic Event หรือ accelerometer ในทดสอบชนจริง; อย่าอนุมานจากแรงนี้โดยไม่รู้มวลเทียบเท่า |

ก่อนหน้านี้การสร้าง Study ใน Fusion กับสำเนา V2 ทำให้แอปปิดตัวสองครั้ง จึงไม่ได้เรียกคำสั่งนี้ซ้ำกับ V3. [Autodesk ระบุผลลัพธ์ Event Simulation](https://help.autodesk.com/cloudhelp/ENU/Fusion-Simulate/files/SIM-EVENT-SIM-RESULTS-CONCEPT.htm) แต่ยังไม่มีผลนั้นสำหรับโครงการนี้. ถ้ากลับมาทำ native study ให้ตรวจวัสดุจริงและข้อต่อก่อน กำหนด contact และ constraint ที่ไม่ยึดเกินจริง แล้วตรวจ mesh convergence และ energy/time step. งานแรกที่มีคุณค่าคือ subassembly plow–bolt–bulkhead และ hinge–pin–cheek ก่อนทั้งคัน.
